CLI Quick Reference & Toolchain

Common commands for Windows, Linux, and Kali environments.

1. Primary Master Routing

Route any cybersecurity task to its exact scenario skill:

Windows (PowerShell) powershell -NoProfile -ExecutionPolicy Bypass -File skills/scripts/master-route.ps1 -Hint "<Task>"
Linux / macOS / Kali bash skills/scripts/master-route.sh --hint "<Task>"

2. Scope & Case Initialization

Initialize work/<case>/scope.md before performing any action:

Windows (PowerShell) powershell -File skills/scripts/case-init.ps1 -Hint "<Task>"
Linux / macOS / Kali bash skills/scripts/case-init.sh --hint "<Task>"

3. Tool Index Refresh & Bootstrap

Detect installed tools and missing dependencies:

Windows Refresh Tool Index powershell -NoProfile -ExecutionPolicy Bypass -File skills/scripts/refresh-tool-index.ps1
Windows Bootstrap Tools powershell -NoProfile -ExecutionPolicy Bypass -File skills/scripts/bootstrap-reverse.ps1

4. Verification & Coherence Tests

Run test suites to verify routing parity:

Verify Routing Coherence powershell -NoProfile -ExecutionPolicy Bypass -File skills/scripts/verify-routing-coherence.ps1
Run Routing Tests powershell -NoProfile -ExecutionPolicy Bypass -File skills/scripts/test-routing.ps1
